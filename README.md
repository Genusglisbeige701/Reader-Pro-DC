## How to Convert PDF to Word

1. Open the application
2. Click File > Export > Word Document
3. Choose output folder
4. Click Export

Your document is now a fully editable Word file with text, images and formatting preserved.

## How to Merge PDF Files

1. Click Tools > Merge PDFs
2. Click Add Files and select documents to combine
3. Drag files to reorder them
4. Click Merge
5. Save the combined file

## How to Compress PDF

1. Open the large file
2. Click File > Optimize PDF
3. Choose compression level (High/Medium/Low)
4. Click Optimize
5. Save the smaller version

## How to Sign PDF

1. Open the document
2. Click Tools > Fill & Sign
3. Click Sign > Add Signature
4. Type, draw or upload your signature
5. Click where you want to place it
6. Save the signed document

## Edit PDF Text

Click the Edit tool, then click directly on any text in the document. You can change wording, fix typos, update information or rewrite entire paragraphs. For scanned documents, use the OCR feature first to convert images to editable text.

## Troubleshooting

**PDF won't open**
- Update to the latest version
- Try File > Repair to fix corrupted documents

**Text editing not working**
- Scanned documents need OCR first (Tools > OCR)
- Image-based PDFs must be converted to text

**Slow with large files**
- Compress first (File > Optimize)
- Close other programs to free RAM
- Split into smaller sections

**Conversion looks wrong**
- Complex layouts may need manual adjustment
- Try different export settings (Tools > Export > Advanced)
